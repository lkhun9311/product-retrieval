# C5 재랭커 v0 계약 (로지스틱 회귀)

초안: 2026-10-05 (메인). 이슈 #9. D20 `rerank.features(query, cand)`, `train(labels) -> reranker_version`, `score(...)`.
학습 곡선(#11)·비교 평가(#10)를 보기 전에 고정한다.

## 1. 재정렬 범위
- 순위 파일(`pr eval` 출력, 질의당 상위 100)에서 **상위 20만** 다시 매긴다. 21–100위는 그대로 둔다.
  근거: c4-v3 §7 "재랭킹은 상위 20 안에서만"(상한 = 검증셋 macro R@20). 이슈 본문의 "상위 100"보다 이 계약이 우선한다.

## 2. 특징 (순위 파일만 사용, 정답 필드는 읽지 않는다)
후보 i(1-based 순위 r, 검색 점수 s_i), 그 질의의 상위 20 점수 s_1..s_20:
1. `score` = s_i
2. `gap_top1` = s_i − s_1
3. `gap_next` = s_i − s_{i+1} (20위는 s_20 − s_21; 21위가 없으면 0)
4. `zscore` = (s_i − mean(s_1..s_20)) / std(s_1..s_20) (std = 0이면 0)
5. `log_rank` = ln(r)
- 이번 버전은 상품 이미지별 유사도(최대·평균)를 쓰지 않는다. 순위 파일에 상품 최댓값만 있어서다. 필요하면 v1에서 순위 파일을 넓힌다.

## 3. 학습
- 입력: 라벨 JSONL(`pr labels` 출력, c4-labels-v1) + **학습셋** 순위 파일.
- 라벨의 (query_id, product_id)가 순위 파일 상위 20에 없으면 실패한다(조용히 버리지 않음). pos·neg 중 하나라도 0개면 실패한다.
- 모델: 특징 표준화(학습 라벨 행의 평균·표준편차) → L2 로지스틱 회귀 (C = 1.0, lbfgs, max_iter 1000), sample_weight = 라벨 weight, 클래스 가중 없음.
- 같은 입력이면 같은 계수(결정적). 저장은 JSON(계수, 절편, 표준화 값, 특징 이름, 설정) — pickle 쓰지 않음.

## 4. 버전
- `reranker_version` = sha256(canonical_json(["c5-rerank-v0", label_version, 학습 순위 파일 sha256, 특징 이름, 하이퍼파라미터, scikit-learn 버전]))의 앞 12자리.
- 저장 위치: `artifacts/rerank/{reranker_version}/model.json`. 같은 버전이 이미 있으면 덮지 않고 내용이 같은지 확인한다.

## 5. 추론
- 입력: model.json + 순위 파일(검증셋 등). 상위 20을 로짓 내림차순으로 다시 매긴다(동점이면 원래 순위).
- 출력 순위 파일: 원래 필드 유지 + `top_k_product_ids` 재정렬, `scores`는 같은 순서로 재배열한 검색 점수, `rerank_scores`(상위 20 로짓), `reranker_version`.
  출력은 기존 평가 코드(`top_k_product_ids`만 읽음)로 그대로 R@K를 잴 수 있다.

## 6. 검증
- 정답 필드를 바꿔도 학습 계수와 추론 순서가 같다(정답 미사용 테스트).
- 특징 손계산 1건, 결정성, 실패 조건(상위 20 밖 라벨, 한 클래스만), 21위 이하 불변, 동점 처리.
